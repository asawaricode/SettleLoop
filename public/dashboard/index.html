Safety Governance

Human-in-the-Loop Safeguard

When a Smart recovery proposal encounters elevated risk or ambiguous failure classifications, it automatically routes to human review instead of executing immediately.

Smart Proposal → Guardrails → Human Review when required → Pending Retry / Stand Down
Core Safety Principle: Human approval changes mandate state; it does not directly execute payment. All financial attempts must route through atomic database validation.
